## P0.1: Error Recovery (unwrap 제거)

### 현황
- `runtime.rs`: **122개** `.unwrap()` (대부분 boa API 호출)
- `frame.rs`: **3개** `.unwrap()`
- `browser.rs`, `session.rs`, `client.rs`: 0개

### 전략

boa_engine API 호출의 대부분은 `Result`를 반환하지만 실패할 일이 거의 없음
(e.g., `js_string!()` 매크로, `ObjectInitializer.build()` 등).
이들은 `let _ =` 로 무시해도 안전함.

**Public API 경로의 unwrap만 제거** (test/내부 코드는 유지):

#### 파일: `crates/oxibrowser-core/src/js/runtime.rs`

**패턴 1: `ObjectInitializer.build()` → `let _ =` 대체**

```rust
// Before:
context.register_global_callable(js_string!("fetch"), 2, fetch_fn).unwrap();
// After:
let _ = context.register_global_callable(js_string!("fetch"), 2, fetch_fn);
```

→ 이미 `let _ =` 패턴 사용 중. 122개 중 대부분이 이 패턴.

**실제로 제거해야 할 위험 unwrap** (검색 결과 기준):

```
grep -n "\.unwrap()" runtime.rs | grep -v "let _ =\|unwrap_or\|#\[test\]"
```

 boa 내부에서 `.unwrap()`을 호출하는 곳:
- `JsValue::from_object()` → `unwrap()` (boa가 반환하는 JsObject)
- `.get()` 체인 → `.unwrap_or(JsValue::undefined())` 이미 사용 중
- `JsArray::new()` → 실패 불가

**실제 작업량**: ~5-10개 위험 unwrap → `unwrap_or_default()` / `?` / `map_err()` 치환

**검증**:
```bash
# public API에서 panic 발생하지 않는지 확인
cargo test --workspace -- --test-threads=1 2>&1 | grep "panic"
```

**예상 LOC 변화**: ±20줄

#### HistoryCommand 채널

```rust
/// Commands from JS history object to Session.
enum HistoryCommand {
    PushState { url: String },
    ReplaceState { url: String },
    Back,
    Forward,
    Go { delta: i32 },
}
```

- `JsRuntime`이 `std::sync::mpsc::Sender<HistoryCommand>` 보유
- `Session::process_js_commands()`에서 수신 후 처리
- 기존 `go_back()` / `go_forward()` 재사용

#### 파일: `crates/oxibrowser-core/src/session.rs`

```rust
/// Process pending JS-initiated history commands.
pub async fn process_history_commands(&mut self, rx: &std::sync::mpsc::Receiver<HistoryCommand>) {
    while let Ok(cmd) = rx.try_recv() {
        match cmd {
            HistoryCommand::PushState { url } => {
                // Add to history without navigation
                if let Ok(parsed) = Url::parse(&url) {
                    self.history.truncate(self.history_index + 1);
                    self.history.push(parsed);
                    self.history_index = self.history.len() - 1;
                }
            }
            HistoryCommand::Back => { let _ = self.go_back().await; }
            HistoryCommand::Forward => { let _ = self.go_forward().await; }
            HistoryCommand::Go { delta } => {
                let target = self.history_index as i32 + delta;
                if target >= 0 && (target as usize) < self.history.len() {
                    self.history_index = target as usize;
                    let url = self.history[self.history_index].clone();
                    let _ = self.navigate(&url.to_string()).await;
                }
            }
            _ => {}
        }
    }
}
```

fn bench_session_memory(c: &mut Criterion) {
    c.bench_function("session_memory_overhead", |b| {
        b.iter(|| {
            let rt = tokio::runtime::Runtime::new().unwrap();
            let before = get_memory_usage();
            let browser = rt.block_on(Browser::new(BrowserConfig::default())).unwrap();
            let _session = browser.new_page("data:text/html,<p>test</p>");
            let after = get_memory_usage();

fn get_memory_usage() -> usize {
    // Use jemalloc stats or /proc/self/status on Linux
    #[cfg(target_os = "linux")]
    {
        let status = std::fs::read_to_string("/proc/self/status").unwrap();
        for line in status.lines() {
            if line.starts_with("VmRSS:") {
                return line.split_whitespace().nth(1).unwrap().parse::<usize>().unwrap() * 1024;
            }
        }
    }
    0
}
