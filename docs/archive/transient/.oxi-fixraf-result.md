## What was done
Replaced broken `requestAnimationFrame` / `cancelAnimationFrame` stubs in
`crates/oxibrowser-core/src/js/runtime.rs` at lines 2522-2539 with a proper
schedule_timer-based implementation. After concurrent edits by other agents,
the rAF/cAF block now sits at lines 2586-2626.

## Implementation
- rAF clones `job_queue` into the closure (matches setTimeout pattern at 1066-1087)
- Callback picked from `args[0]`, checked with `is_callable()`
- Schedule fires after `Duration::from_millis(16)` (~60fps)
- DOMHighResTimeStamp computed as `SystemTime::now()...duration_since(UNIX_EPOCH).as_secs_f64() * 1000.0`
- Returns `JsValue::from(id as f64)`
- cancelAnimationFrame clones `job_queue`, calls `cancel_timer(id as u64)`, returns undefined
- Both use `unsafe { NativeFunction::from_closure(...) }` per boa idiom
