# OxiBrowser v0.7.0 설계서

> **목표**: v0.6.0의 5가지 한계 중 headless에 필요한 3가지를 근본적으로 해결  
> **불필요한 것 제외**: 이벤트 버블링, form.submit(), rAF 프레임 대기 — headless에서 의미 없음

---

## 해결할 문제 (3가지)

| # | 문제 | 현재 증상 | 영향 |
|---|------|-----------|------|
| 1 | **mutation 미적용** | `createElement`+`appendChild` 후 다음 evaluate에서 요소 사라짐 | 모든 DOM 조작이 단일 evaluate 내에서만 유효 |
| 2 | **style/classList가 함수** | `el.style.setProperty()`가 아니라 `el.style().setProperty()` | React, Vue, 일반 라이브러리 호환성 깨짐 |
| 3 | **textContent/innerHTML 읽기 전용** | `.property()`로 정적 등록, setter 없음 | React의 `el.textContent = '...'` 동작 안 함 |

### 해결하지 않을 것 (headless에 불필요)

| 항목 | 이유 |
|------|------|
| 이벤트 버블링 | AI 에이전트는 `click()` 직접 호출, 캡처/버블 필요 없음 |
| `form.submit()` | 폼 제출은 HTTP 요청으로 처리, 브라우저 네비게이션 불필요 |
| `requestAnimationFrame` 프레임 동기화 | headless는 렌더링 프레임 없음, 즉시 실행이 정상 |
| CSS 레이아웃 엔진 | Phase 4 이후, v0.7.0 범위 아님 |

## 문제 1: mutation 미적용 (근본 원인)

### 현재 동작

```
evaluate("createElement + appendChild")
    ↓
1. JS 스레드: snapshot에 노드 삽입 + DomMutation 기록
2. 메인 스레드: drain_mutations() → apply_mutations()
3. apply_mutations(): CreateElement/AppendChild → {} (no-op!)
4. inject_dom_snapshot(): from_frame()으로 전체 snapshot 재생성
5. 새 snapshot에는 JS에서 만든 노드가 없음 → 요소 사라짐
```

### 해결: webapi DOM에 mutation 적용

`apply_mutations()`에서 webapi DOM을 직접 조작:

```rust
fn apply_mutations(&mut self, mutations: &[DomMutation]) {
    for m in mutations {
        match m {
            // ── 기존 (작동 중) ──
            DomMutation::SetAttribute { node_id, name, value } => { /* 동일 */ }
            DomMutation::SetTextContent { node_id, text } => { /* 동일 */ }
            DomMutation::InputElement { node_id, value } => { /* 동일 */ }
            DomMutation::ClickElement { node_id } => { /* 동일 */ }

            // ── 새로 구현 ──
            DomMutation::CreateElement { node_id, tag } => {
                if let Some(page) = &mut self.active_page {
                    let frame = page.root_frame_mut();
                    let nid = NodeId(*node_id as usize);
                    // webapi Document에 새 Element 노드 생성
                    frame.document_mut().create_element_node(nid, tag);
                }
            }
            DomMutation::CreateTextNode { node_id, text } => {
                if let Some(page) = &mut self.active_page {
                    let frame = page.root_frame_mut();
                    let nid = NodeId(*node_id as usize);
                    frame.document_mut().create_text_node(nid, text);
                }
            }
            DomMutation::AppendChild { parent_id, child_id } => {
                if let Some(page) = &mut self.active_page {
                    let frame = page.root_frame_mut();
                    let pid = NodeId(*parent_id as usize);
                    let cid = NodeId(*child_id as usize);
                    frame.document_mut().tree_mut().append_child(pid, cid);
                }
            }
            DomMutation::RemoveChild { parent_id, child_id } => {
                if let Some(page) = &mut self.active_page {
                    let frame = page.root_frame_mut();
                    let pid = NodeId(*parent_id as usize);
                    let cid = NodeId(*child_id as usize);
                    if let Some(children) = frame.document_mut().tree_mut().children_mut(pid) {
                        children.retain(|&c| c != cid);
                    }
                    frame.document_mut().tree_mut().remove_parent(cid);
                }
            }
            DomMutation::SetInnerHtml { node_id, html } => {
                // HTML 파싱 후 자식 교체 — 복잡도가 높아 v0.7.0에서는
                // textContent setter와 동일하게 처리
                if let Some(page) = &mut self.active_page {
                    page.root_frame_mut().set_text_content(
                        NodeId(*node_id as usize), html,
                    );
                }
            }
        }
    }
}
```

### webapi DOM에 필요한新增 메서드

```rust
// crates/oxibrowser-webapi/src/dom/document.rs

impl Document {
    /// 주어진 ID로 Element 노드를 생성하여 노드 맵에 등록
    pub fn create_element_node(&mut self, id: NodeId, tag: &str) {
        let node = Node::new(id, NodeType::Element {
            tag: tag.to_string(),
            attributes: HashMap::new(),
        });
        self.nodes.insert(id, node);
    }

    /// 주어진 ID로 Text 노드를 생성하여 노드 맵에 등록
    pub fn create_text_node(&mut self, id: NodeId, text: &str) {
        let node = Node::new(id, NodeType::Text(text.to_string()));
        self.nodes.insert(id, node);
    }

    /// Tree의 가변 참조 반환 (append_child 등에 필요)
    pub fn tree_mut(&mut self) -> &mut Tree {
        &mut self.tree
    }

    /// 노드 맵의 가변 참조 반환
    pub fn nodes_mut(&mut self) -> &mut HashMap<NodeId, Node> {
        &mut self.nodes
    }
}
```

### Frame에 필요한 메서드

```rust
// crates/oxibrowser-core/src/frame.rs

impl Frame {
    pub fn document_mut(&mut self) -> &mut Document {
        &mut self.document
    }
}
```

### 결과

mutation 적용 후 `inject_dom_snapshot()`이 `from_frame()`을 호출하면,
webapi DOM에 이미 새 노드가 반영되어 있으므로 새 snapshot에도 포함됩니다.

## 문제 2: style/classList를 접근자로 변경

### 현재

```rust
.function(style_fn, js_string!("style"), 0)      // el.style()
.function(classlist_fn, js_string!("classList"), 0) // el.classList()
```

JS에서 `el.style`은 `function` 타입이고, 반드시 `el.style()`로 호출해야 합니다.
React, Vue 등은 `el.style.setProperty()`를 기대하므로 호환되지 않습니다.

### 해결: `.accessor()`로 등록

`.accessor()`는 getter 함수를 등록하여 `el.style`을 프로퍼티처럼 접근할 수 있게 합니다.
이미 `firstChild`, `lastChild`, `value`에서 사용한 패턴과 동일합니다.

```rust
// style getter — FunctionObjectBuilder로 변환 필요
let style_getter_fn = FunctionObjectBuilder::new(ctx.realm(), style_fn)
    .name(js_string!("get style"))
    .build();

// classList getter
let classlist_getter_fn = FunctionObjectBuilder::new(ctx.realm(), classlist_fn)
    .name(js_string!("get classList"))
    .build();

// 체인에서:
.accessor(
    js_string!("style"),
    Some(style_getter_fn),
    None,
    Attribute::all(),
)
.accessor(
    js_string!("classList"),
    Some(classlist_getter_fn),
    None,
    Attribute::all(),
)
```

**주의**: 기존 `.function(style_fn, ...)` 제거 후 `.accessor(...)`로 교체.

### 검증 포인트

boa의 `ObjectInitializer.accessor()`는 getter로 `JsFunction`을 받습니다.
`NativeFunction` → `JsFunction` 변환은 `FunctionObjectBuilder::new(ctx.realm(), fn).build()`로 이미 검증됨 (value getter 패턴과 동일).

## 문제 3: textContent/innerHTML setter

### 현재

```rust
.property(
    js_string!("textContent"),
    JsValue::from(JsString::from(node.text_content.as_str())),
    Attribute::all(),
)
.property(
    js_string!("innerHTML"),
    JsValue::from(JsString::from(node.text_content.as_str())),
    Attribute::all(),
)
```

`.property()`는 정적 값만 설정. setter가 없어 `el.textContent = 'new'`가 불가합니다.

### 해결: `.accessor()`로 변경

```rust
// textContent getter
let dom_snap_tc = dom_snapshot_arc.clone();
let nid_tc = node.id;
let text_content_getter = unsafe {
    NativeFunction::from_closure(move |_this, _args, _ctx| {
        let dom = dom_snap_tc.read();
        if let Some(ref s) = *dom {
            if let Some(n) = s.nodes.get(&nid_tc) {
                return Ok(JsValue::from(JsString::from(n.text_content.as_str())));
            }
        }
        Ok(JsValue::from(JsString::from("")))
    })
};
let text_content_getter_fn = FunctionObjectBuilder::new(ctx.realm(), text_content_getter)
    .name(js_string!("get textContent"))
    .build();

// textContent setter — snapshot 업데이트 + mutation 기록
let dom_snap_tcs = dom_snapshot_arc.clone();
let nid_tcs = node.id;
let mut_tcs = mutations.clone();
let text_content_setter = unsafe {
    NativeFunction::from_closure(move |_this, args, _ctx| {
        let text = args.first()
            .and_then(|v| v.as_string())
            .map(|s| s.to_std_string_escaped())
            .unwrap_or_default();
        {
            let mut dom = dom_snap_tcs.write();
            if let Some(ref mut s) = *dom {
                if let Some(n) = s.nodes.get_mut(&nid_tcs) {
                    n.text_content = text.clone();
                }
            }
        }
        mut_tcs.write().push(DomMutation::SetTextContent {
            node_id: nid_tcs,
            text,
        });
        Ok(JsValue::undefined())
    })
};
let text_content_setter_fn = FunctionObjectBuilder::new(ctx.realm(), text_content_setter)
    .name(js_string!("set textContent"))
    .build();

// 체인에서:
.accessor(
    js_string!("textContent"),
    Some(text_content_getter_fn),
    Some(text_content_setter_fn),
    Attribute::all(),
)
```

`innerHTML`도 동일한 패턴으로 구현 (setter에서 `DomMutation::SetInnerHtml` 기록).

## 변경 파일 요약

| 파일 | 변경 내용 | 난이도 |
|------|-----------|--------|
| `webapi/src/dom/document.rs` | `create_element_node`, `create_text_node`, `tree_mut`, `nodes_mut` 추가 | ★☆☆ |
| `webapi/src/dom/tree.rs` | 변경 없음 (`append_child` 이미 존재) | — |
| `core/src/frame.rs` | `document_mut()` 추가 | ★☆☆ |
| `core/src/session.rs` | `apply_mutations()`에 CreateElement/AppendChild/RemoveChild/CreateTextNode 구현 | ★★☆ |
| `core/src/js/runtime.rs` | (a) style/classList: `.function()` → `.accessor()` (b) textContent/innerHTML: `.property()` → `.accessor()` | ★★★ |

## 구현 순서

```
Step 1: webapi DOM API 확장 (document.rs + frame.rs)
        — create_element_node, create_text_node, tree_mut, document_mut
        — 단위 테스트로 검증

Step 2: session.rs apply_mutations() 구현
        — CreateElement, CreateTextNode, AppendChild, RemoveChild, SetInnerHtml
        — 통합 테스트: createElement → appendChild → 다음 evaluate에서 querySelector

Step 3: runtime.rs style/classList 접근자 변경
        — .function() → .accessor()
        — 테스트: el.style.setProperty() (괄호 없이)

Step 4: runtime.rs textContent/innerHTML setter
        — .property() → .accessor() with getter + setter
        — 테스트: el.textContent = 'new'; el.textContent === 'new'

Step 5: 전체 시나리오 테스트
        — 27개 기존 시나리오 + 새 시나리오 추가
```

## 검증 기준

v0.7.0은 다음이 모두 통과해야 완료:

```javascript
// 1. mutation 지속성
var el = document.createElement('div');
el.setAttribute('id', 'persist');
document.querySelector('body').appendChild(el);
// ← 다음 evaluate에서도
document.querySelector('#persist') !== null;  // true

// 2. style/classList 프로퍼티 접근
var s = document.querySelector('h1').style;
typeof s;                    // "object" (not "function")
s.setProperty('color', 'red');
s.getPropertyValue('color'); // "red"

var cl = document.querySelector('h1').classList;
typeof cl;                   // "object" (not "function")
cl.add('new-class');
cl.contains('new-class');   // true

// 3. textContent setter
document.querySelector('h1').textContent = 'Modified';
document.querySelector('h1').textContent; // "Modified"
```

## 위험 분석

| 위험 | 가능성 | 영향 | 완화 |
|------|--------|------|------|
| webapi Document에 NodeId 충돌 | 중 | 노드 덮어쓰기 | NEXT_NODE_ID 시작값을 webapi 노드 ID 범위 밖으로 설정 (현재 1,000,000+) |
| `from_frame()` 재생성 시 새 노드 누락 | 낮 | querySelector 실패 | webapi DOM에 노드를 추가했으므로 from_frame이 자동 포함 |
| accessor가 기존 `.function()` 체인과 충돌 | 낮 | 빌드 실패 | 기존 `value` accessor 패턴과 동일 |
| textContent setter가 자식 노드를 지우지 않음 | 중 | DOM 불일치 | v0.7.0에서는 텍스트만 업데이트, 자식 제거는 v0.8.0 |
